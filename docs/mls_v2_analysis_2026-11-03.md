**问题定位：已有证据支持的解释与边界**

1. **GRT 与官方 STA 对关键路径的判断严重不同，是当前最优先的问题。** 官方 baseline 最差终点为 `bp_fe_pc_gen_1/genblk1_branch_prediction_1/btb_1/_5005_/D`，slack 为 -4.00944 ns；同一终点在内部 baseline 仅为 -0.705916 ns。官方 v2 最差终点为同模块 `_4531_/D`，slack 为 -4.13761 ns，内部最终值仅 -0.697373 ns。这两个终点在相应内部快照中均未进入采样路径集合。即使接受判据使用全设计内部 STA，它也无法弥补内部模型把官方关键路径判断为不够关键的问题。

   官方两份最差路径报告均从 `reset_i` 出发，经过 `input1194/Z` 和 `btb_1/_3465_/ZN`。该 NOR4 输出对应的报告增量约由 4.49 ns 变为 4.61 ns；终点及后续分支有所变化，不能把全部 WNS 退化直接归因于这一个单元，但这条 reset→BTB 路径应成为下一步核对 RC、负载和 slew 的首要对象。

2. **局部预测无法解释全局重布线收益。** 最终方案预测影响 24 个终点、TNS 收益 0.18156 ns，而实测内部全设计收益为 186.36206 ns，约相差 1,026 倍。重新汇总完整终点快照后，这 24 个预测终点的实际净收益只有 0.82281 ns，约占全设计净收益的 0.44%。因此绝大部分实测变化发生在预测集合之外。

   更直接的证据是：5,999 个受约束终点中 5,998 个 slack 发生变化；对保留名称的背景网比较无向路由线段集合，Bottom 有 6,453 / 31,768 个网发生变化，Upper 有 164 / 1,149 个网发生变化。完整 GRT 重跑造成了广泛变化，不能把 +186 ns 都归为 `net1249` 本身的局部 RC 优化。这里的计数是线段集合变化，不是已证明的物理几何差异或随机性统计。

   内部 TNS 改善也伴随违例分布变化：1,866 个终点的负 slack 改善，1,488 个恶化；新增 67 个 setup 负 slack 终点，消除 0 个，违例终点数由 3,287 增至 3,354。TNS 改善代表负 slack 总量减轻，不代表更多终点满足时序。

3. **预测与实际层分配不一致，有明确可修正对象。** 12 个候选的含层号路径 Jaccard 全为 0。`net1249` 六个变体均预测走 `metal15`，实际走 `metal11`；`icache_1/_04784_` 六个变体均预测走 `metal18`，实际走 `metal12`。忽略层号后，其中 9 个候选的二维网格边完全重合，其他 3 个重合度为 0.667–0.857。主要偏差在层分配，不应将它笼统解释成二维路径搜索完全失败。

   最终 006 的预测是 `metal15` 上 3 条边，实际为 `metal11` 上 2 条边。规划器产出的路径没有写成强制 guide，FastRoute 会自行选择层。根据本次导出的 RC，metal15 与 metal11 的单位电阻相差约 40 倍，metal18 与 metal12 相差约 95 倍，直接把预测层路径当成实际 RC 的代表缺少依据。此证据能解释预测不准的一部分，但不能单独证明它造成了最终 DRT 的 220.69 ns TNS 退化。

4. **路径采样覆盖有限，且受模型偏差影响。** 两个状态均达到 2,000 条路径上限并标记 truncated。baseline 覆盖 677 / 3,287 个违例终点，即 20.60%，覆盖负 slack 总量的 29.68%；最终覆盖 669 / 3,354 个，即 19.95%，覆盖负 slack 总量的 27.04%。这是候选生成的覆盖率，不是全设计接受判据的覆盖率。单纯扩大路径数量可能有帮助，但不能替代 GRT→DRT 时序校准。

5. **没有发现发布错误或新增注释缺口的证据。** 发布哈希核验通过；官方 HBT RC 注入为 1,151 个、每个 3 Ω / 0.6 fF，与 v2 声明模型一致。baseline、v1 smoke、v1、v2 的 parasitic annotation 报告逐字节相同，均为 4,362 个 unannotated drivers、0 个 partially unannotated drivers。这个已有问题需要正确理解，但不能据此声称 v2 新增了注释丢失，也不能声称全设计寄生注释完整。

上述结论证明了模型和搜索覆盖存在偏差。单个 case、单次搜索、单个最终官方评估，尚不能建立所有候选的 GRT→DRT 相关性，也不能区分所有背景网变化的因果贡献；需要更细的路径/RC 对照和少量官方候选复评。

| P1 | 用实际 GRT 层分配校准候选层成本，分别报告二维边重合和含层边重合 | 消除 metal15/18 预测与 metal11/12 实测的系统偏差；不以仅修改展示指标替代模型修正 |
| P1 | 在时序校准后补充 overflow/拥塞退化保护，检查多目标权重 | 避免很大的内部 TNS 数值压过布线风险；阈值通过同条件消融实验确定 |
| P2 | 扩展路径采样并覆盖官方关键路径族，再单独测试树切分、重定位或交换 | 分辨采样覆盖改善与算法新功能的贡献，避免多开关同时改变难以归因 |

当前最值得保留的是完整验证、回滚和可追溯产物机制；最需要修正的是其依赖的时序代理和候选预算分配。增加接受网数或直接增大 `max_trials` 可能消耗更多算力，但现有证据尚不支持它们会解决最终时序退化。
